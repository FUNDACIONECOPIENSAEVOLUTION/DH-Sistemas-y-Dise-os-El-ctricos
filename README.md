# DH · David Hernández | Sistemas y Diseños Eléctricos

Sitio institucional estático basado en la identidad corporativa aprobada (puño metálico con rayo dorado, monograma DH oro/plata). Versión **1.0.0** (octubre 2026).

## Contenido
- `index.html`: landing page, 13 especialidades, metodología, identidad y contacto.
- `styles.css`: diseño corporativo responsive, accesibilidad y estilos móviles.
- `app.js`: filtros, detalles de servicios, menú móvil y composición de cotizaciones por WhatsApp.
- `portafolio.html`: versión digital/para impresión del portafolio.
- `docs/portafolio-dh-david-hernandez.pdf`: portafolio corporativo de 10 páginas para descargar.
- `scripts/generate_portfolio.py`: generador programático del portafolio PDF, basado en ReportLab y la identidad de marca.

## Publicación
Sitio GitHub Pages desde la rama `main` y carpeta `/` (raíz). Si GitHub Pages no está activado, en `Settings → Pages` seleccionar `Deploy from a branch → main → /(root)` y guardar.

Dirección esperada: `https://fundacionecopiensaevolution.github.io/DH-Sistemas-y-Dise-os-El-ctricos/`.

## Actualizar PDF
`pip install reportlab pillow && python scripts/generate_portfolio.py`
